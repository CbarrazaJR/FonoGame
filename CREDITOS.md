# Créditos e recursos

- Referência de interface, textos e personagem: modelo FonoGame, versão 7, fornecido pelo usuário: https://www.figma.com/make/rLEORzB8mtZudd2S0DieEa/Jogo-Educacional-para-Pr%C3%A9-escola?p=f
- Referência do banco de perguntas: documento “Preguntas para a Curricularização Final (1).docx”, fornecido pelo usuário. A procedência de cada pergunta está em PERGUNTAS.md.
- Fotografias do Unsplash presentes no modelo:
  - Parque das Esculturas: https://images.unsplash.com/photo-1671240430657-3462d32baa5b
  - Casa: https://images.unsplash.com/photo-1705895360045-7442f5b55d21

- Fredoka e Nunito: Google Fonts, distribuídas sob a SIL Open Font License. Os textos originais das licenças estão em assets/fonts/Fredoka-OFL.txt e assets/fonts/Nunito-OFL.txt.
- Os emojis da interface são exibidos pela fonte de emojis do dispositivo.
- As ilustrações SVG adicionais foram criadas para as atividades do documento fornecido. As alternativas usam fotografias, ilustrações, letras, palavras ou números.
- Os efeitos sonoros são sintetizados no navegador. A narração utiliza a Web Speech API e as vozes disponíveis no sistema ou navegador.

O pacote contém a aplicação e seus recursos locais. O editor e os controles da interface do Figma não fazem parte da aplicação.
